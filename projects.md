Build a **modern, clean, user-friendly personal AI assistant website** for automating my daily work and repetitive tasks.

The main idea is to store my **personal instructions, prompts, commands, shortcuts, and workflows** so I can reuse them quickly instead of doing the same work manually.

### Core Features

- **Daily Status:** Convert my raw updates into my predefined exact format.
- **Prompt Rewriter:** Improve rough prompts for clearer and better AI output.
- **Text Refiner:** Refine messages for clients, managers, and coworkers with selectable tones.
- **Task Generator:** Turn a task title/rough idea into a structured developer task with requirements and acceptance criteria.
- **Command & Shortcut Library:** Save terminal/Git/Flutter/Xcode commands, shortcuts, prompts, snippets, and useful notes.
- **Saved Instructions:** Create reusable AI instructions for each workflow.
- **Search & Favorites:** Quickly find saved prompts, commands, and workflows.
- **History:** Keep recently generated results.
- **Dashboard:** Provide quick access to frequently used tools and saved items.

### UX

Make it feel like a **personal productivity tool, not a ChatGPT clone**. Prioritize speed, simplicity, copy-to-clipboard, keyboard shortcuts, clean navigation, and minimal clicks.

### AI

Use **Google AI API as the primary provider and Groq as a fallback**. Keep the AI layer modular so providers/models can easily be changed later.

Build the MVP with a **scalable, clean architecture** so more AI tools and automations can be added easily in the future.
